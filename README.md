# Landi Kubëza — Modern Albanian Portfolio

A responsive static portfolio website for Landi Kubëza.

## Included
- Supplied company logo
- Five supplied project photos
- Albanian copy focused on gardening, paving/kubëza, brick work and outdoor spaces
- Contact section at the very end
- Responsive mobile navigation
- No build step required

## Contact information
The exact phone/WhatsApp/email values were not available in the current project files, so the contact buttons are intentionally marked with placeholders (`PHONE_NUMBER`, `WHATSAPP_NUMBER`, `EMAIL_ADDRESS`) rather than inventing business details. Replace those three values in `index.html` with the business contact details before publishing.

## Deploy
Push the folder to GitHub and import the repository into Vercel. No framework or build command is required.
